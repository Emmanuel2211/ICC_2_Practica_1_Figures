# Práctica 1: Herencia y Clases en Python

**Alumno:** Emmanuel Cruz Durán

Este proyecto implementa una jerarquía de clases geométricas utilizando Programación Orientada a Objetos en Python. Se hace uso de clases abstractas (TDA) e importaciones relativas para calcular el área y perímetro de distintas figuras geométricas.

## Requisitos
* Python $>=$ 3.14

## Estructura del Proyecto
* `src/`: Contiene el código fuente. Incluye el script principal `practica1.py` y el paquete `fig/` con las clases geométricas.
* `doc/`: Contiene la documentación del código generada en formato HTML.
* `Reporte.pdf`: Reporte teórico con la definición formal de los algoritmos y análisis crítico.

## Cómo ejecutar el código
Para ejecutar el programa principal, sitúate en la carpeta `src/` y corre el archivo `practica1.py`:

```bash
cd src/
python practica1.py
```
